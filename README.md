# Watermark Studio

一个简洁、现代的浏览器端图片水印工具。无需服务器，所有处理均在本地完成，保护您的隐私。

## 功能特性

- **拖拽上传** - 支持拖放文件或点击选择，操作直观
- **实时预览** - 所有参数调整即时可见
- **文字水印** - 自定义水印文字内容
- **丰富自定义选项**
  - 字体大小调节
  - 颜色选择器
  - 透明度控制
  - 旋转角度调整
- **多种布局模式**
  - 九宫格定位（左上、居中、右下等）
  - 平铺模式（全图覆盖）
- **一键导出** - 生成 PNG 格式图片并下载
- **隐私安全** - 纯本地处理，图片不上传服务器

## 快速开始

### 在线使用
直接在浏览器中打开 `index.html` 文件即可使用。

### 本地运行
由于项目使用 ES6 模块和 Canvas API，建议通过本地服务器运行：

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js (需安装 http-server)
npx http-server

# 然后在浏览器访问
# http://localhost:8000
```

## 使用说明

1. **上传图片**
   - 将图片拖放到上传区域
   - 或点击上传区域选择文件
   - 支持 JPG、PNG、WebP 格式

2. **编辑水印**
   - 在右侧控制面板输入水印文字
   - 调整字体大小和颜色
   - 设置透明度和旋转角度
   - 选择水印位置或开启平铺模式

3. **下载图片**
   - 点击「下载图片」按钮
   - 图片将以 PNG 格式保存到本地

## 技术栈

- **HTML5** - 语义化结构
- **CSS3** - Tailwind CSS + 自定义属性
- **JavaScript** - 原生 ES6+，无框架依赖
- **Canvas API** - 图像处理与渲染

## 配置说明

如需自定义默认配置，可修改以下变量：

```javascript
// 默认水印文字
watermarkText.value = '© 版权所有'

// 默认字体大小
fontSize.value = 32

// 默认透明度 (0-100)
opacity.value = 50

// 默认旋转角度 (-180 ~ 180)
rotation.value = -30
```

## 无障碍支持

- 完整的键盘导航支持
- ARIA 标签标注
- 尊重 `prefers-reduced-motion` 系统设置
- 清晰的焦点状态指示

## 性能优化

- 大图自动缩放（限制最大 1200px）
- 防抖处理避免频繁重绘
- CSS 硬件加速动画

## 已知限制

- 不支持 GIF 动图（仅保留首帧）
- 不支持 SVG 格式直接处理
- 单文件最大支持约 20MB（受浏览器内存限制）
